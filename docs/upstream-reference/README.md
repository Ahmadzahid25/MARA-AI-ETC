# Upstream reference documents

The files in this folder (`COMMUNITY.md`, `ISSUE_TRIAGE.md`, `CREDITS.md`, `CITATION.cff`) describe the **upstream OpenHands / OpenHands Agent Canvas open-source project** — its community channels, issue-triage process, contributors, and academic citation. They are kept for attribution and reference (see [`docs/repo-audit/02-problems-found.md`](../repo-audit/02-problems-found.md) Problem P-06 and P-13), not because they describe this repository's own process.

For MARA AI-ETC's own contribution process, see [`CONTRIBUTING.md`](../../CONTRIBUTING.md) and [`docs/repo-audit/05-development-guidelines.md`](../repo-audit/05-development-guidelines.md).

`LICENSE` (at the repository root) is left in place, not moved here — its terms apply to this repository regardless of MARA-specific process changes, and its review is tracked separately (ACCB Condition C-4, [`docs/governance/architecture-approval-report.md`](../governance/architecture-approval-report.md)) as a legal/procurement matter, not a documentation-organization one.
